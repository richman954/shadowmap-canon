==================================================
II. SHADOWMAP DEFINITION
==================================================

ShadowMap is a method for recovering hidden invariant structure by analyzing a secondary representation of an object when the object is not fully intelligible, not fully separable, or not operationally useful in its primary representation.

Compressed meta-form:
Start with an object that is only partially legible in its native form.
Generate a transformed, reflected, residual, corrected, reconstructed, or monitored representation.
Extract invariant structure from that secondary representation.
Use the recovered structure to predict, classify, control, or solve.

Primary rule:
ShadowMap is not mere paraphrase, praise, or summary.
A valid ShadowMap must identify:
1. the visible object
2. the primary representation
3. the opacity or failure mode of that representation
4. the shadow operator or shadow representation
5. the hidden structure recovered
6. the invariant or low-dimensional summary
7. the governing mathematics or logic
8. the practical or strategic use

V. CANONIZED SHADOWMAP FAMILIES
==================================================

A. GEOMETRIC / REFLECTIVE
Use when repeated reflections, copies, tilings, images, or mirrored domains reveal structure not obvious in the base object.

Canonical pattern:
base domain -> reflected orbit -> invariant formula / kernel / constraint

Typical signals:
tilings
reflection groups
image or mirror orbits
kernel formulas from repeated copies

B. SPECTRAL / RESPONSE
Use when the clean primary picture breaks down but a response function or spectral observable still carries the hidden order.

Canonical pattern:
object -> response function -> hidden order / crossing / phase / mode structure

Typical signals:
spectral crossings
response asymmetry
non-quasiparticle order still visible in a response observable

C. RESIDUAL / DISCREPANCY
Use when the informative object is the difference between model and reality, survivor and non-survivor, prediction and observation, or fit and residual.

Canonical pattern:
primary model + residual field -> hidden fragility / correction / systematic bias

Typical signals:
error fields
bias maps
observation-model mismatch
residual geometry

D. ROUTE / PATH / NETWORK
Use when the final object is less informative than the family of routes, transitions, disconnections, or graph paths that generate it.

Canonical pattern:
target object -> route family / graph neighborhood -> hidden constraint / optimal path geometry

Typical signals:
retrosynthetic disconnections
network bottlenecks
route minimality
path degeneracy

E. FIELD / SOLVER / GEOMETRY-TO-PHYSICS
Use when geometry and boundary conditions cast a latent field that is more useful than the geometry alone.

Canonical pattern:
geometry + BCs -> solved field -> hidden force / flux / energy landscape

Typical signals:
FEM or PDE solves
field-line structure
flux or force maps
hidden geometry-induced physics

F. KINETIC / SPIN / REACTION-NETWORK
Use when an observed signal is one projection of a hidden state-population flow.

Canonical pattern:
observable channel -> kinetic network -> hidden intermediate manifold

Typical signals:
relaxation curves
EPR or ODMR signatures
state-population flow
multi-state reaction networks

G. MONITORED-DYNAMICAL / TRAJECTORY-CONTROL
Use when the primary object is a partially observed, stochastic, continuously monitored, or feedback-controlled trajectory.

Canonical pattern:
observed trajectory -> reconstructed hidden generator -> asymmetry functional -> control deformation -> work / output dual

Canonical variables:
gamma = observed trajectory or monitored record
G[gamma] = latent generator reconstructed from gamma
A[gamma] = path asymmetry functional
C_lambda = control family acting on the generator or trajectory
W_lambda = operational, thermodynamic, or performance dual

Canonical questions:
1. What is the observed trajectory gamma?
2. Can gamma be lifted to a latent generator G[gamma]?
3. Is there a scalar or low-dimensional asymmetry functional A[gamma]?
4. Is there a control parameter lambda that deforms A[gamma]?
5. Does the same lambda also control work, cost, energy flow, gain, or output W_lambda?
6. Is the real hidden structure in state space, path space, generator space, or dual work space?


H. TENSOR-MESSAGE / LOOP-RESIDUAL
Use when a high-dimensional object has many locally interacting parts and the hidden structure is better represented as messages on a graph plus residuals from loops, feedback, or higher-order corrections.

Canonical pattern:
object -> factor/tensor graph -> message fixed point -> loop residual -> hidden invariant

Typical signals:
factor graphs
tensor networks
local compatibility tables
belief-propagation messages
loopy feedback
loop residuals
high-residual bottleneck subgraphs

Canonical caution:
Message passing is a projection, not a guarantee of exactness.
Treat loop residuals as evidence of hidden coupling, contradiction, memory, feedback, or higher-order interaction that the local fixed point failed to absorb.

VI. CORPUS-DERIVED EXTENSIONS
==================================================

These are durable additions inferred from the current project corpus and promoted into the master canon.

1. PROJECTION-RESIDUAL / KERNEL-ENERGY SUBRULE
When a high-dimensional state vector is projected onto a survivorship, stability, or principal subspace, treat the orthogonal residual as hidden fragility, kernel energy, or survivor-miss structure.

Canonical pattern:
x -> projection P(x) -> residual (I-P)(x)

Useful outputs:
survivor score
kernel energy
victim score
residual hot spots
cross-sectional ranking

Interpretation:
A strong primary score does not exhaust the object.
Residual structure may carry the real hidden risk.

2. OBSERVATIONAL-CORRECTION SUBRULE
When a physics model is structured but imperfect, do not discard the physics first.
Keep the dynamical core or governing scaffold, and learn or infer the residual, correction field, or discrepancy structure from observations.

Canonical pattern:
physics core + observational discrepancy -> corrected dynamics

Interpretation:
The shadow may be the correction field, not a replacement model.

3. HIDDEN-MEMORY / INTERNAL-FIELD SUBRULE
When hysteresis appears, search for a latent memory coordinate q(t) or equivalent internal state that conditions the present response by retained history.

Canonical pattern:
history -> q(t) -> effective internal coordinate -> observable

Default form:
qdot = (q_inf(u) - q) / tau_q
effective_state = applied_state - chi * q

Interpretation:
The primary knob is often not the true state variable.
It modulates rates through a hidden internal coordinate with memory.

4. CHANNEL-PROJECTION SUBRULE
When the observed signal is only one channel of a larger hidden network, reconstruct the hidden state graph and the rate structure.

Canonical pattern:
visible channel y -> hidden network xdot = f(x) -> inferred states and rates

Interpretation:
The visible observable is often a projection of hidden state flow, not the state itself.

5. SHADOW-OF-THE-SHADOW RULE
If the primary representation breaks down, but a response function, residual, monitored record, or reconstructed field still carries the order, treat that as a strong ShadowMap case.

Interpretation:
The hidden structure may live in the secondary representation, not in the primary one.

6. GEOREFLECT FINITE-CELL SUBRULE
When a circular-polygon cell is generated by finitely many reflection boundaries and the reflected orbit closes, do not solve the PDE directly in the cell first.
Construct the closed reflection orbit, compress the orbit into finite orbit products P and Q, and recover the kernel from that compressed orbit.

Canonical pattern:
cell + finite reflection generators -> closed reflection orbit -> orbit products P,Q -> kernel

Interpretation:
The visible cell is not the deepest object.
The closed reflection orbit carries the operational kernel.

Typical signals:
rational-angle sectors
lens or lune cells from two circles
finite parqueting cells
representative cells in double-reflection constructions

Canonization note:
Canonize the orbit-compression rule, not paper-specific formulas.

7. GENERATOR-SPACE / EVALUATOR-LANDSCAPE SUBRULE
When the native object is hard to search directly but concise generators, heuristics, policies, or acquisition rules can be evaluated and scored, do not search the raw object first.
Search a constrained generator family under an evaluator-defined fitness landscape, then inspect the surviving generators for a reduced symmetry, rule, or policy manifold.

Canonical pattern:
native object -> concise generator g -> evaluator E[g] -> retained generator family -> extracted reduced rule / new restricted search space

Useful outputs:
generator prior
score signature
reduced symmetry class
compressed policy rule
new restricted search space

Interpretation:
The target object is not the deepest search variable.
The evaluator-shaped generator manifold carries the operational structure.

Typical signals:
easy-to-evaluate / hard-to-solve problems
algorithm skeleton with one crucial subfunction
program or policy search with explicit scoring
diverse database, islands, or evolutionary retention
human-inspectable discovered generators that reveal a reusable compressed rule

Canonization note:
Canonize the generator-search / evaluator-landscape rule, not LLM-specific, benchmark-specific, or hyperparameter-specific details.


8. TENSOR-MESSAGE / LOOP-RESIDUAL COMPRESSION SUBRULE
When a system is high-dimensional and locally interacting, tensorize it before interpreting it. Represent local mechanisms as node tensors or factors and shared couplings as edges, run message passing to obtain a stable local projection, and rank hidden structure by the residual introduced by loops, feedback, or higher-order corrections.

Canonical pattern:
object -> factor/tensor graph -> message fixed point -> loop residual -> hidden invariant

Interpretation:
The object is not the deepest variable; the message network plus loop residual is.
The message fixed point is the first shadow.
The loop residual is the shadow-of-the-shadow.

Useful outputs:
interaction graph
local factor or tensor tables
converged message set
approximate observable projection
loop-residual energy
high-residual bottleneck subgraphs
dominant residual-loop class

Relation to existing canon:
This subrule computationalizes projection-residual / kernel-energy, hidden-memory / internal-field, channel-projection, shadow-of-the-shadow, kinetic / spin / reaction-network, and field / solver / geometry-to-physics cases.

Canonization note:
Canonize the message-plus-loop-residual rule, not quantum Hamiltonian constants, tensor-network hyperparameters, LEC kinetic constants, financial-feature weights, or the claim that belief propagation is exact for all loopy ShadowMap graphs.

==================================================
IX. STRENGTH CRITERIA
==================================================

A case is strong when at least two of the following hold:
1. the shadow representation reveals a variable or invariant the primary representation hid
2. the recovered structure supports prediction or inverse inference
3. the recovered structure gives a control or design principle
4. the recovered structure unifies multiple observables
5. the hidden structure is mathematically tighter than the source rhetoric

A case is weak when:
the secondary representation is only a restatement
the hidden variable is speculative without support
the mathematics does not close
the shadow adds no predictive or operational value

Current canonical monitored-dynamics principle:

Current canonical memory principle:
When an observable shows hysteresis or path dependence, search for a hidden memory coordinate and an effective internal variable that it conditions.

Current canonical tensor-message principle:
When a high-dimensional object is locally interacting, represent it as a factor/tensor graph, use message passing as the first shadow when appropriate, and treat loop residuals as candidate kernel energy for hidden coupling, feedback, or higher-order structure.
