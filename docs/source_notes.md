# Source notes

This repository stores derived ShadowMap canon files and runnable structural utilities.

Large source artifacts such as PDFs, source ZIP bundles, and spreadsheets are intentionally not committed in this scaffold. The repo keeps distilled text canon, submodule, exemplar, patch, update-action, and result artifacts.

## Canon authority

Current working canon alias:

- `docs/canon/SHADOWMAP_MASTER_CANON_CURRENT.txt`
- `docs/canon/SHADOWMAP_MASTER_CANON_SOURCE_MAP_CURRENT.txt`

REV_C canonical files are preserved under their original names in `docs/canon/`.

## Tensor-message computational artifacts

Runnable package code lives in `src/shadowmap/`.

The transfer test script writes regenerated outputs to `data/results/tensor_message_transfer_results.{json,csv}`.

## Publication note

This repo is a scaffold. Before publishing, decide whether to keep derived text only or add selected source artifacts under a documented license policy.
