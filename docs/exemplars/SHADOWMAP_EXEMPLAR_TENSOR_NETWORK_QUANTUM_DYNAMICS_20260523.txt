PURPOSE
This note preserves the tensor-network quantum-dynamics case as a worked ShadowMap exemplar.
The goal is not to restate the quantum-computing result, but to extract the reusable ShadowMap kernel: geometry-matched local compression, message propagation, and loop-residual correction.

OBJECT
Disordered quantum spin-glass dynamics on two- and three-dimensional lattices.

PRIMARY REPRESENTATION
A many-body quantum wavefunction under a time-dependent Hamiltonian. In native form this object is high-dimensional and hard to simulate directly.

EXPLICIT CLAIM
The paper argues that lattice-specific tensor networks, evolved with belief-propagation simple update and measured with corrected message-passing methods, can simulate quantum annealing dynamics efficiently and accurately on classical computers.

WHAT THE DATA / MODEL / EQUATIONS ACTUALLY SHOW
The operational pipeline is:
1. encode the wavefunction in a tensor network matching the lattice geometry
2. time evolve with BP-based simple update
3. optionally truncate with BP
4. measure observables using loop corrections or MPS message passing
5. compare two-point correlators and scaling behavior

The important ShadowMap point is not merely that the simulation works, but that the global object is replaced by a local graph of messages plus controlled residual corrections.

SHADOW OPERATOR
Lattice-matched tensorization plus message passing.

SHADOW SPACE
- tensor network geometry
- local tensors
- edge messages
- BP fixed point
- loop-corrected contractions
- MPS boundary messages on planar/cylindrical structures

HIDDEN STRUCTURE RECOVERED
The high-dimensional wavefunction becomes legible through local compatibility messages and through the loop terms that local BP misses.

INVARIANT OR LOW-DIMENSIONAL SUMMARY
message fixed point + loop residual

or:
wavefunction -> geometry-matched tensor network -> BP messages -> loop-corrected observables

GOVERNING MATH
Factor contraction:
Z = sum_{x_e} prod_v T_v(x_{partial v})

BP update:
m_{u->v}(x_uv) proportional_to sum_{x_{partial u \ v}} T_u(x_{partial u}) prod_{w neq v} m_{w->u}(x_wu)

Loop residual:
K_loop = |log Z_corrected - log Z_BP|

Observable residual:
K_loop(O) = |O_corrected - O_BP|
