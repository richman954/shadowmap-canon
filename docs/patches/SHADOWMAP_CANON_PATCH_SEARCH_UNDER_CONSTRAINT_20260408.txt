Core rule
When a visible object is the survivor of sequential choice under active constraints, do not ShadowMap the finished artifact first.
Project it into its constrained-search skeleton, recover the feasible manifold, evaluator geometry, and active bottlenecks, then compress the survivor path into a reusable invariant.

native object -> constrained generator or policy -> feasible trajectories -> evaluator-shaped survivors -> invariant

- it contributes a durable reusable projection rather than a one-off domain detail
