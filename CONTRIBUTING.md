# Contributing to ShadowMap Canon

Welcome to the ShadowMap Canon repository! We appreciate your contributions. Please follow these guidelines:

* **No large source files:** Do not add large PDFs, ZIPs, XLSX files, or external research-source documents into the repository.
* **Canon files are reviewed manually:** Canon files (in `docs/canon/`) are the source of truth and must not be altered arbitrarily. Any changes here are reviewed manually and semantics should not be changed without explicit instruction.
* **Code changes require tests:** If you change code, you must include a test covering that change, or explain clearly why no test is applicable.
* **Generated artifacts:** Any generated artifacts must belong under `data/results` or `artifacts`, and absolutely not under `docs/canon`.
